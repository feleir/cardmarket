Cardmarket Optimizer

v0.1.0 · runs entirely in your browser on cardmarket.com · no account, no server

Reads one of your wants lists, fetches the offers for every card (only from the seller countries you allow), and works out the cheapest combination of sellers including shipping. Then it can put the result in your cart.

Install on Android (Chrome)

  3. Name it cmopt, and replace the URL with what you copied (39 KB). Save.
  4. Open cardmarket.com → Wants and log in.
  5. Tap the address bar, type cmopt, and tap the bookmark suggestion (with the ☆). The optimizer opens over the page.

Chrome only runs bookmarklets started from the address bar like this, not from the bookmarks screen. Tip: if you use Chrome sync, add the bookmarklet once on desktop and it shows up on your phone.

Desktop

Drag this to your bookmarks bar: ⚡ cmopt

Firefox for Android / Tampermonkey

Install a userscript manager (Tampermonkey or Violentmonkey), then install cm-optimizer.user.js. A ⚡ Optimize button appears on every Cardmarket page.

Good to know

  • It fetches about one page per card (more for "any printing" wants), with a pause between pages to avoid rate limits. A 100-card list takes a few minutes. Fetched pages are cached for 30 minutes, so you can change optimizer settings and run again fast.
  • Shipping is an estimate from editable tiers (Setup → Optimizer → Shipping estimates). Your cart shows Cardmarket's real shipping before you pay.
  • If Cardmarket shows a browser check, pass it on any page, then run again. Pages it already fetched are kept.
